\section{Data records}\label{records}

KG v3.0.1 contains 45,707,660 asserted triples from 16 manifested
modules and is archived at Zenodo \cite{rubalkhali_kg301}. The deposit contains the modules listed in Table~\ref{tab:modules},
the combined asserted graph, and a reproducibility package with code,
term definitions and validation evidence. The modules use RDF/XML and
Turtle; the combined graph uses compressed N-Quads. Shared site, specimen and
process identifiers connect observations across modules. The deposit also includes an inventory with checksums.

The accompanying data repository described in Data Availability contains:
\begin{itemize}
\item A specimen catalogue linking collection visits, specimens,
extractions, libraries and sequence runs.
\item Amplicon counts and taxonomic mappings, field environmental
observations, daily climate inputs and monthly climate summaries.
\item Laboratory and field XRF values, the chemical mapping table for
93 reporting channels, and archived-soil pH measurements
(\texttt{EQ-PH-SHARED-v1.0.1}).
\item The paired PMA profiles, 150 CoverM profiles, eggNOG annotations
for the 990-genome analytical subset, and six source tables for the
MAG-derived versus PICRUSt2 comparison.
\item A data dictionary defining fields, data types, units and missing-value
conventions; a climate inventory with acquisition metadata; and a file inventory
with sizes, checksums, licensing status and bulk-data retrieval information.
\item Validation schemas, SPARQL queries, expected query outputs and
source comparisons.
\end{itemize}
Tabular data use delimited text formats; larger collections are compressed.
