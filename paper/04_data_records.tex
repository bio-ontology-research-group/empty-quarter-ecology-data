\section{Data records}\label{records}

KG v3.0.1 contains 45,707,660 asserted triples from 16
modules and is archived at Zenodo \cite{rubalkhali_kg301}. The resource contains the modules listed in Table~\ref{tab:modules},
the combined asserted graph, and a reproducibility package with code,
term definitions and validation evidence. The modules use RDF/XML and
Turtle, and the combined graph uses compressed N-Quads. Shared site, sample and
process identifiers connect observations across modules. The deposit also includes an inventory with checksums.

The accompanying data repository described in Data Availability contains:
\begin{itemize}
\item A sample catalogue linking collection visits, samples,
extractions, libraries and sequence runs.
\item Amplicon counts and taxonomic mappings, field environmental
observations, daily climate inputs and monthly climate summaries.
\item Laboratory and field XRF values, the chemical mapping table for
93 reporting channels, and archived-soil pH measurements
(\texttt{EQ-PH-SHARED-v1.0.1}).
\item The refined MAG catalogue: 5,438 genome FASTAs with per-genome
checksums, source-library and binning provenance, CheckM2 quality estimates
and GTDB R232 classifications, together with MIMAG quality tiers and the
ENA accessions of each library, assembly, bin and MAG. Shotgun library
metadata covers 551 read-bearing libraries (Section~\ref{methods:shotgun}).
\item Functional annotations of the refined MAG catalogue: per-genome
counts of KOs, CAZy families, Pfam domains and preferred gene names,
per-genome numbers of predicted and annotated proteins, and the tool
versions and checksums of each genome's annotation.
\item Coverage profiles of the 551 shotgun libraries against the refined
MAG catalogue, with the mapping reference definition that assigns each
contig to its genome.
\item The paired PMA profiles and the ecology-analysis inputs: 150
CoverM profiles from Trips~1--3 against the 991-genome catalogue,
eggNOG annotations supporting its 990-genome analytical subset, and six
source tables for the MAG-derived versus PICRUSt2 comparison.
\item A data dictionary defining fields, data types, units and missing-value
conventions; a climate inventory with acquisition metadata; and a file inventory
with sizes, checksums, licensing status and bulk-data retrieval information.
\item Validation schemas, SPARQL queries, expected query outputs and
source comparisons.
\end{itemize}
Tabular data use delimited text formats while larger collections are compressed.
