\section{Data records}\label{records}

KG v3.0.1 contains 45,707,660 asserted triples from 16 manifested
modules and is archived at Zenodo \cite{rubalkhali_kg301}. The deposit
provides the RDF/XML and Turtle modules in Table~\ref{tab:modules},
a compressed N-Quads export of their deduplicated union, and code to
load the modules and reproduce that export. Shared site, specimen and
process identifiers connect observations across modules. The
\href{https://bio2vec.net/data/empty-quarter/kg/3.0.1/manifest.json}{release manifest}
identifies each deposited file and its checksum.

The \href{https://github.com/bio-ontology-research-group/empty-quarter-ecology-data}{data repository}
provides the specimen catalogue, assay tables and analysis inputs.
The catalogue links specimens to collection visits, extractions,
libraries and sequence runs. Tabular products include amplicon counts
and taxonomic mappings, field environmental observations, laboratory
and field XRF values, and archived-soil pH measurements
(\texttt{EQ-PH-SHARED-v1.0.1}). The repository also provides the paired
PMA profiles, 150 CoverM profiles, eggNOG annotations for the
990-genome analytical subset, and six source tables for the
MAG-derived versus PICRUSt2 comparison. Tables are supplied in
delimited text formats; larger collections are compressed.
The \href{https://github.com/bio-ontology-research-group/empty-quarter-ecology-data/blob/main/metadata/climate/current_analysis_inputs.json}{climate inventory} identifies daily inputs; monthly climate
summaries retain separate acquisition metadata.

The \href{https://github.com/bio-ontology-research-group/empty-quarter-ecology-data/blob/main/metadata/DATA_DICTIONARY.tsv}{data dictionary} defines
fields, data types, units and missing-value conventions for the curated
tables. Site and campaign identify collection visits; specimen and
assay identifiers distinguish physical material from its measurements.
Control roles, processing batches and quality-control dispositions
support selection of observations for reuse. Missing values and
unresolved mappings retain the conventions documented for each table.
The \href{https://github.com/bio-ontology-research-group/empty-quarter-ecology-data/blob/main/PRE_RELEASE_MANIFEST.tsv}{file inventory} gives locations,
sizes, checksums and licensing status. A separate bulk-data inventory
gives retrieval information for larger downloads. The repository also supplies
validation schemas, SPARQL queries, expected query outputs and the
source comparisons described in Technical Validation.
