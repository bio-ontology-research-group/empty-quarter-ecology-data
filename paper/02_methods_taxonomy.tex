\subsection{Taxonomy normalization and mapping}
\label{methods:taxonomy}
A taxonomic label can denote different taxa across databases and releases, and a taxon can be referred to by several labels \cite{balvovciute2017silva}. To ensure consistent identification, we retained SILVA assignments for each ASV and linked it to either a validated NCBI Taxonomy identifier or a project-specific identifier when no suitable NCBI Taxonomy identifier was found.

Each SILVA assignment describes the organism across seven ranks from domain to species, and may include an additional species prediction and a confidence score. We used the species name from the rank assignment in the knowledge graph and kept the additional species assignment as an annotation. Before mapping, we removed prefixes from taxon names and explicitly recorded missing and unclassified ranks.

For each SILVA assignment, we checked for a candidate NCBI identifier from a fixed NCBI Taxonomy release (OBO Foundry NCBITaxon r2025-03-13 built from NCBI Taxonomy 1 March 2025). A candidate was only accepted if the identifier exists in that release, its rank matches, its name matches the SILVA name or a documented synonym, and its parent taxa in NCBI match identifiers already accepted for the higher ranks of the same assignment. When no candidate met these criteria, the name was given a project-specific identifier, which refers to a unique combination of rank, name, and parent taxa. As a result, users can therefore query each ASV by its original SILVA assignment or by its NCBI or project identifier.


% A taxonomic label can denote different taxa across databases and
% releases, and a taxon can have several labels \cite{balvovciute2017silva}. To make the assignments comparable across datasets, we mapped SILVA lineages to NCBI Taxonomy using the OBO Foundry NCBITaxon r2025-03-13 (NCBI Taxonomy retrieved 1 March 2025). When no valid NCBI identifier was found, we created an identifier for this project. We accepted a mapped NCBI identifier only when its name, taxonomic rank, and position in the classification were consistent with the original SILVA assignment. This prevented assigning an identifier to a taxon when its classification conflicted with the source lineage.
