# Amplicon processing: canonical command, configuration and portable samplesheet

This directory carries what a reuser needs to re-run the amplicon step, and
states plainly what is still missing.

## Canonical command

The canonical Trips 1-5 feature table was produced by nf-core/ampliseq 2.14.0:

```bash
nextflow run nf-core/ampliseq \
    -r 2.14.0 \
    -profile singularity \
    --input combined_samplesheet.csv \
    --outdir ./results \
    --FW_primer "CCTACGGGNGGCWGCAG" \
    --RV_primer "GACTACHVGGGTATCTAATCC" \
    --illumina_novaseq \
    --dada2_ref_taxonomy silva=138.2 \
    --skip_qiime \
    -c ampliseq_resources.config
```

The reverse primer in this command is `GACTACHVGGGTATCTAATCC` (Bakt_785R),
which is what the raw reads support and what the corrected protocol record
states. Taxonomy is assigned by DADA2 against SILVA 138.2; `--skip_qiime`
means the QIIME 2 steps under `analysis/scripts/` are a separate branch and
did not produce the canonical table.

`ampliseq_resources.config` is the resource configuration used for the run.

## Portable samplesheet

`combined_samplesheet_portable.csv` is regenerated by
`scripts/amplicon/build_portable_samplesheet.py` from the two deposited
submission sheets. It has 1,268 rows, one per deposited run, covering 1,238
distinct sample names; 30 identifiers carry a second library and are suffixed
`__lib2`. Read paths are written as `${EQ_READS_DIR}/<run>_1.fastq.gz`, so:

```bash
export EQ_READS_DIR=/path/to/fastq
```

`combined_samplesheet_accessions.tsv` carries the run, biosample, experiment
and library accessions plus campaign, compartment and control status for each
row, so the sheet can also be driven from a local mirror with different file
names.

## What is not reproducible from this directory

- The run accessions are registered under BioProject `PRJEB106069` (umbrella
  `PRJEB104209`). At the time of writing `PRJEB106069` returns no public record
  and none of the runs resolve publicly, so the samplesheet is portable in
  structure but cannot yet be resolved from the archive alone. See
  `evidence/accessions/accession_reconciliation.json` in the extracted
  candidate package.
- The exact `combined_samplesheet.csv` used on the cluster is not archived; it
  carried absolute IBEX scratch paths. The sheet here is an equivalent rebuilt
  from the submission records, not a byte copy.
- No container digest was recorded for the `-profile singularity` run, so the
  exact image versions are not pinned.

## Downstream filtering

The canonical table is unfiltered: it contains all 351,472 ASVs and still
includes the 24 negative-control profiles. Contaminant screening on the
canonical table is `scripts/controls/contaminant_prevalence.py`. The QIIME 2
filtering branch under `analysis/scripts/` used a minimum feature frequency of
5 and a minimum of 2 samples, and it operated on a different, smaller table.
