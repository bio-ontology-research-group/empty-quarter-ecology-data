# Frozen pH ecology sensitivity

Dataset version: `EQ-PH-ECOLOGY-v1.0.0`. Analysis version: `ph-ecology-v1.0.0`.

The immutable, incomplete workbook contributed 643 exact pH/specimen/ecology joins and 503 site-campaign-position groups.
Group-mean pH ranged from 7.290 to 8.530.

The pipeline tests exact specimen reconciliation, site-fixed alpha models, paired position contrasts, Bray-Curtis and Aitchison composition models, and a same-cohort geographic model before and after pH adjustment.

Rows that are pending, depleted, date-ambiguous, or suspected column shifts are absent from every model. Availability is non-random, so results are bounded to this fixed cohort.

Later measurements must be released as a successor data-paper version; they do not replace or mutate this ecology-paper analysis.
